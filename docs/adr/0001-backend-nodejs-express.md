# Izbira Node.js in Express za backend

## Status
Sprejeto

## Kontekst in problem
Za backend sem moral izbrati jezik in ogrodje. Znam JavaScript, Javo in Python, zato sem se moral odločiti, s čim bom delal - predvsem glede na to, da je to moj prvi večji spletni projekt in bi rad, da je razvoj čim bolj enostaven.

## Obravnavane alternative
- Node.js z Express (JavaScript)
- Python z Flask
- Java s Spring Boot

## Sprejeta odločitev
Odločil sem se za Node.js z Express. Frontend tako ali tako pišem v JavaScriptu, zato se mi je zdelo smiselno uporabiti isti jezik tudi na backendu - tako mi ni treba hkrati skakati med dvema jezikoma. Express je poleg tega precej preprost za uporabo, kar mi je pomagalo, da sem hitreje razumel, kako strežnik sploh deluje.

## Posledice

### Pozitivne
- En jezik za cel projekt, kar mi olajša razumevanje lastne kode.
- Ogromno vadnic in primerov na spletu, če kje obtičim.
- Hiter zagon, brez veliko začetnega nastavljanja.

### Negativne
- Python in Java imata v nekaterih primerih (npr. večji sistemi, znanstveno računalništvo) bolj razvit ekosistem, kar tukaj ne pride v poštev.
- JavaScript ne preverja tipov tako strogo kot npr. Java, zato se določene napake pokažejo šele ob zagonu, ne prej.
